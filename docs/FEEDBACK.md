# InvestX — Feedback & Community

We love hearing from users, developers, and the community. Your feedback directly shapes InvestX.

---

## How to Share Feedback

### Bug Reports
Found a bug? Please open a GitHub Issue with:
- A clear description of what happened vs. what you expected
- Steps to reproduce
- Your browser, OS, and Freighter version
- Any screenshots or console errors

[Open a Bug Report →](https://github.com/anindhabiswas25/InvestX/issues/new?labels=bug&template=bug_report.md)

---

### Feature Requests
Have an idea to improve the platform? We welcome feature suggestions:
- Describe the feature and the problem it solves
- Explain who benefits from it (investor, business owner, voter)
- Optional: suggest an implementation approach

[Request a Feature →](https://github.com/anindhabiswas25/InvestX/issues/new?labels=enhancement&template=feature_request.md)

## Code Contributions

Pull requests are welcome! Please read [README.md](../README.md#local-setup) for setup instructions.

For significant changes:
1. Open an issue first to discuss the change
2. Fork the repository and work on a feature branch
3. Follow the existing code style (ESLint enforced)
4. Ensure CI checks pass before requesting review
